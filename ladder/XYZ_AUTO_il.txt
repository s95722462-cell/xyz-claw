# [5/6] XYZ_AUTO : 자동 운전 — 점 목록(최대 8점)을 돌며 Z 위로 → XY 보간 이동 → Z 내림 → 머묾 → Z 위로 → 다음 점
# 점 목록 D3100~ : 점마다 6워드 = X(32) Y(32) Z(32) 0.1um.  P1 D3100, P2 D3106, ... P8 D3142
# 설정: D3150 점 개수(1~8), D3152 Z 안전 높이(32), D3154 XY 속도(32, 0.01mm/min), D3156 Z 속도(32), D3158 머묾 x0.1초, D3161 반복 횟수
# 상태: D3160 지금 점 번호, D3162 끝난 반복, D3170 단계 (0 대기, 10/11 Z 위로, 20/21 XY, 30/31 Z 내림, 40 머묾, 50/51 Z 위로, 60 다음 점)
# QD75 위치결정 데이터: X(축1) No.10 = ABS 2축 직선 보간(H0AF4: 제어 0AH, 보간축=축2, 가감속 No.3), Y(축2) No.10 = 목표 Y
#                      Z(축3) No.11 = 내림 목표, No.12 = 안전 높이 (H01F0: ABS 1축, 가감속 No.3)
# 버퍼: 축 n 의 데이터 No.k = 2000/8000/14000 + (k-1)x10 : +0 식별자, +4 속도(32), +6 위치(32)

// 1. 처음 값 (샘플: RUN 할 때마다 넣음. 실제는 래치 영역·GOT 입력으로)
LD SM402
MOV K4 D3150
DMOV K100000 D3152
DMOV K300000 D3154
DMOV K100000 D3156
MOV K5 D3158
MOV K1 D3161
DMOV K500000 D3100
DMOV K500000 D3102
DMOV K300000 D3104
DMOV K1500000 D3106
DMOV K500000 D3108
DMOV K300000 D3110
DMOV K1500000 D3112
DMOV K1200000 D3114
DMOV K400000 D3116
DMOV K500000 D3118
DMOV K1200000 D3120
DMOV K300000 D3122

// 2. 점 개수 1~8 로 제한, 지금 점의 목록 위치 Z5 = (점 번호 - 1) x 6
LD< D3150 K1
MOV K1 D3150
LD> D3150 K8
MOV K8 D3150
LD SM400
- D3160 K1 D3168
* D3168 K6 D3172
MOV D3172 Z5

// 3. 자동 시작 (GOT M3012): 자동 모드·운전 가능·원점 완료·자동 중 아님
LD M3012
PLS M3061
LD M3061
AND M3016
AND M3005
AND M3040
ANI M3060
SET M3060
RST M3062
MOV K1 D3160
MOV K0 D3162
MOV K10 D3170

// 4. 사이클 정지 (GOT M3013 또는 자동 중 수동 모드로 바꿈): 지금 점을 마치고 끝냄
LD M3013
ORI M3016
AND M3060
SET M3062

// 5. 단계 10: Z 안전 높이로 (No.12)
LD= D3170 K10
MOV H1F0 U6\G14110
DMOV D3156 U6\G14114
DMOV D3152 U6\G14116
MOV K12 D3182
SET M3240
MOV K11 D3170
LD= D3170 K11
AND M3243
RST M3243
MOV K20 D3170

// 6. 단계 20: XY 보간 이동 (X No.10 기준축, Y No.10 보간축 목표)
LD= D3170 K20
MOV H0AF4 U6\G2090
DMOV D3154 U6\G2094
DMOV D3100Z5 U6\G2096
DMOV D3102Z5 U6\G8096
MOV K10 D3180
SET M3200
MOV K21 D3170
LD= D3170 K21
AND M3203
RST M3203
MOV K30 D3170

// 7. 단계 30: Z 내림 (No.11)
LD= D3170 K30
MOV H1F0 U6\G14100
DMOV D3156 U6\G14104
DMOV D3104Z5 U6\G14106
MOV K11 D3182
SET M3240
MOV K31 D3170
LD= D3170 K31
AND M3243
RST M3243
MOV K40 D3170

// 8. 단계 40: 머묾 (D3158 x 0.1초)
LD= D3170 K40
OUT T1450 D3158
LD= D3170 K40
AND T1450
MOV K50 D3170

// 9. 단계 50: Z 다시 위로 (No.12)
LD= D3170 K50
MOV K12 D3182
SET M3240
MOV K51 D3170
LD= D3170 K51
AND M3243
RST M3243
MOV K60 D3170

// 10. 단계 60: 다음 점. 마지막 점이면 반복 +1. 반복 다 했거나 사이클 정지면 끝, 아니면 단계 20
LD= D3170 K60
INC D3160
LD= D3170 K60
AND> D3160 D3150
MOV K1 D3160
INC D3162
LD= D3170 K60
LD>= D3162 D3161
OR M3062
ANB
RST M3060
RST M3062
MOV K0 D3170
LD= D3170 K60
MOV K20 D3170
