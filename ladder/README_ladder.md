## 구성 (가정 — 실제에 맞게 바꿀 것)
- QD75MH4 선두 I/O 0060: 축1 = X, 축2 = Y, 축3 = Z (MR-J4-B 3대)
- 입력: X0 비상정지 정상(b접점), X1 도어 닫힘
- 단위: 위치 0.1 µm (1 mm = 10000), 속도 0.01 mm/min, **Z 는 위가 0, 아래로 +**

## QD75 위치결정 데이터 (프로그램이 매번 써 넣음)
- X No.10: `H0AF4` = ABS 2축 직선 보간(0AH), 보간축 = 축2, 가감속 No.3 / Y No.10: 목표 Y
- Z No.11: 내림 목표, No.12: 안전 높이 (`H01F0` = ABS 1축)
- 원점 복귀 = 기동 번호 9001 (원점 파라미터는 MRC2/GX Configurator 에서 축마다 설정해야 함)

## 실제 장비에 넣기 전에
1. 축 번호·I/O·입력 X0/X1 을 실제 배선에 맞게
2. 디바이스 번호가 기존 프로그램과 겹치지 않는지 (학습 랙 기존 프로그램과 M3000·D3000 대는 미확인)
3. 소프트 리밋(Pr.12/13)·원점 파라미터·가감속 시간 No.3 설정
4. 시뮬레이터에서는 QD75 버퍼(U6\G)를 못 써서 바로 시험 불가 → 실기는 저속·카메라로 확인하며

## 검토 후 고친 것 (2026-11-06 11:11, Rebuild All 오류 0 다시 확인)
1. 이동 끝 판정: 위치결정 완료(X74~76) → **BUSY 꺼짐 + 축 에러 없음**. 원점 복귀는 위치결정 완료 신호가 안 켜져서 원점 순서가 멈추던 문제
2. 원점 복귀 중 M3101 추가 → 원점 중 JOG 금지
3. 이동 시간 초과(10초)는 원점 중 제외, 원점 복귀 시간 초과 M1423(60초) 따로
4. 자동 중 수동 모드로 바꾸면 사이클 정지 (점 마치고 멈춤)
5. 에러 리셋 값(Cd.5)을 버튼 뗄 때 0 으로 되돌림
남은 확인 거리(실기): QD75 원점 파라미터, 2축 보간 속도 기준(Pr.20), 가감속 No.3 값
