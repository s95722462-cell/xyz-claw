# [1/6] XYZ_SYS : XYZ 3축 샘플 — 준비·서보 ON·모드·정지·리셋·모니터 (2026-11-06 샘플)
# 구성(가정): Q13UDV + QD75MH4 (선두 I/O 0060, 축1=X 축2=Y 축3=Z) + MR-J4-B x3
# QD75 신호: X60 READY, X61 동기, X68/X69/X6A 축 에러, X6C/X6D/X6E BUSY, X70~72 기동 완료, X74~76 위치결정 완료
#            Y60 PLC READY, Y61 서보 ON(전축), Y64~66 축 정지, Y70~72 위치결정 기동, Y68~6D JOG(X+ X- Y+ Y- Z+ Z-)
# 가정 입력(실제 배선에 맞게 바꿀 것): X0 비상정지 정상(b접점, 정상 ON), X1 도어 닫힘(정상 ON)
# 단위: 위치 0.1um (1mm = 10000), 속도 0.01mm/min, Z 는 위가 0 (아래로 갈수록 +)
#
# 유닛 비트 블록 M3000~ (실무 패턴 오프셋): 3032 도어 열림, 3036 에러 리셋, 3040 원점 완료(전축),
#   3056 일시정지, 3060 자동 운전 중, 3061 자동 시작 펄스, 3062 사이클 정지 중, 3064 수동 운전 중, 3075 중알람
# GOT 버튼(가정): M3010 정지, M3011 에러 리셋, M3012 자동 시작, M3013 사이클 정지, M3014 원점 복귀 시작,
#   M3016 자동 모드 선택(ON 자동 / OFF 수동), M3017 서보 OFF 요청

// 1. 모니터: 현재 위치 D3000 X / D3002 Y / D3004 Z (32비트 0.1um), 에러 번호 D3006 X / D3007 Y / D3008 Z
LD SM400
DMOV U6\G800 D3000
DMOV U6\G900 D3002
DMOV U6\G1000 D3004
MOV U6\G806 D3006
MOV U6\G906 D3007
MOV U6\G1006 D3008

// 2. 안전 입력: 비상정지(X0 b접점) 끊기면 M3003, 도어 열림 M3032
LDI X0
OUT M3003
LDI X1
OUT M3032

// 3. 에러 리셋 펄스 M3036 (GOT M3011) → QD75 Cd.5 축 에러 리셋 (에러가 있는 축만)
LD M3011
PLS M3036
LD M3036
AND X68
MOV K1 U6\G1502
LD M3036
AND X69
MOV K1 U6\G1602
LD M3036
AND X6A
MOV K1 U6\G1702
LDF M3011
MOV K0 U6\G1502
MOV K0 U6\G1602
MOV K0 U6\G1702

// 4. 정상 M3007 = 중알람 없음·정지 버튼 아님·서보 OFF 요청 아님·비상정지 아님
LDI M3075
ANI M3010
ANI M3017
ANI M3003
OUT M3007

// 5. PLC READY, 서보 ON (비상정지·서보 OFF 요청이면 OFF)
LD SM400
OUT Y60
LDI M3017
ANI M3003
OUT Y61

// 6. 운전 가능 M3005 = QD75 READY·동기·서보 ON·정상
LD X60
AND X61
AND Y61
AND M3007
OUT M3005

// 7. 원점 완료가 풀리는 경우: 서보 OFF·QD75 READY 꺼짐
LDI Y61
ORI X60
RST M3040

// 8. 정지 처리: 정상이 아니면 전축 정지, 모든 이동 요구·자동·원점 순서 초기화
LDI M3007
OUT Y64
OUT Y65
OUT Y66
RST M3060
MOV K0 D3170
MOV K0 D3190
BKRST M3200 K16
BKRST M3220 K16
BKRST M3240 K16

// 9. 모드: 자동 모드 M3016 ON 이면 자동, OFF 면 수동 운전 가능 M3064
LDI M3016
AND M3005
ANI M3060
OUT M3064
