# [3/6] XYZ_HOME : 원점 복귀 — 안전 순서: Z 먼저 위로(원점) → X·Y 동시 → 원점 완료 M3040
# 수동 모드(M3064)에서 GOT M3014 로 시작. 순서 단계 D3190 (0 대기, 1 Z, 2 XY, 3 확인)
# QD75 기계 원점복귀 = 기동 번호 9001

// 1. 시작: 수동 모드·원점 순서 중 아님
LD M3014
AND M3064
PLS M3100
LD M3100
LD= D3190 K0
ANB
RST M3040
MOV K1 D3190

// 1-1. 원점 복귀 중 M3101 (JOG 막기·시간 초과 구분용)
LD<> D3190 K0
OUT M3101

// 2. Z 원점 먼저
LD= D3190 K1
MOV K9001 D3182
SET M3240
MOV K2 D3190

// 3. Z 끝나면 X·Y 동시 원점
LD= D3190 K2
AND M3243
RST M3243
MOV K9001 D3180
MOV K9001 D3181
SET M3200
SET M3220
MOV K3 D3190

// 4. X·Y 둘 다 끝나면 원점 완료
LD= D3190 K3
AND M3203
AND M3223
RST M3203
RST M3223
SET M3040
MOV K0 D3190
