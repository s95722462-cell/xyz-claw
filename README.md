# XYZ 인형 뽑기

미쓰비시 Q 시리즈 학습 랙용으로 만든 **XYZ 3축 래더 프로그램(7개)을 브라우저에서 그대로 실행**하고, 그 래더로 3D 인형 뽑기 기계를 움직입니다.

- 바로 하기: https://s95722462-cell.github.io/xyz-claw/
- 래더 시뮬레이터(점 목록·알람·래더 원문 보기): https://s95722462-cell.github.io/xyz-claw/gantry.html

## 어떻게 움직이나
1. `ladder/` 의 명령 리스트(XYZ_SYS·ERR·HOME·MANU·AUTO·MT·GOT, 685줄)를 브라우저 안 해석기가 4ms 마다 한 줄씩 실행합니다 (LD·AND·OUT·MOV·DMOV·D/·E*·MPS·타이머 등).
2. 가짜 **QD75MH4 3축**이 래더의 출력(Y70~72 기동, Y68~6D JOG, Y64~66 정지)과 버퍼 지령(기동 번호, 위치결정 데이터)을 받아 움직이고, 결과를 래더 입력(X6C BUSY, X74 위치결정 완료, 현재값)으로 돌려줍니다. 원점 복귀 9001, X·Y 2축 직선 보간, Z 1축, 스트로크 에러를 흉내 냅니다.
3. 인형 뽑기 화면:
   - 조이스틱(방향키) = 래더 JOG 버튼 M3020~M3023
   - 뽑기(스페이스) = 점 목록을 2점으로 채우고 래더 자동 운전(M3016·M3012). P1 = 지금 X·Y 에서 쌓인 높이까지 내려가기, P2 = 출구 위
   - 래더 자동 단계 40(머묾)에서 P1 이면 집게를 오므리고 P2 면 벌립니다
   - 집게 흔들림은 래더 축 가속도로 계산한 진자 운동, 모터 소리는 축 속도에서 만듭니다

실제 PLC 와 연결된 것은 아닙니다. 래더를 PLC 에 넣기 전에 동작·인터락·알람을 눈으로 확인하는 도구입니다. 가짜 QD75 의 스트로크(X 0~220, Y 0~160, Z 0~60mm)·속도·가감속은 동작 확인용 가정값입니다.

## 놀이
- 동전 넣기 → 방향키로 조준(20초) → 스페이스로 뽑기
- 상품 9종: 곰돌이·토끼·병아리·고양이·고무 오리·로봇·비치볼·선물 상자·주사위 (종류마다 잘 잡히는 정도가 다름, 2층으로 쌓임)
- 소리·배경 음악·목소리(브라우저 한국어 음성)는 첫 클릭 뒤 시작, 오른쪽 위에서 끌 수 있음
- 드래그 = 둘러보기

## 파일
| 경로 | 내용 |
|---|---|
| `ladder/` | XYZ 래더 원문 7개 + 설명 (`README_ladder.md`) |
| `src/claw_template.html` | 인형 뽑기 (three.js r128, 소리, 게임) |
| `src/gantry_template.html` | 래더 해석기 + 가짜 QD75 + 2D 갠트리 시뮬레이터 |
| `build.py` | 래더 원문을 넣어 `index.html`·`gantry.html` 생성 |
| `tests/` | Playwright 시험 (원점 → 조준 → 뽑기 → 득템, 비상 정지·리셋) |

```bash
python build.py                     # 래더를 고친 뒤 다시 만들기
npm i playwright && node tests/claw.test.cjs && node tests/gantry.test.cjs
```

## 이 도구로 찾은 래더 버그
`XYZ_ERR` 알람 자기유지 해제가 한 스캔 펄스(M3036)라서, 축 에러 알람이 에러 리셋 한 번에 안 풀렸습니다 (그 스캔에는 축 에러 신호가 아직 켜져 있음). 해제 조건을 버튼을 누르는 동안(M3011)으로 바꿔 고쳤습니다.
